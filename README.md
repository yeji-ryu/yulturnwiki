# 🌳 Yulturn Wiki

> “What if interns could write a mini Namuwiki about each other?”


## ✨ Concept

This project is a community-driven internal wiki where interns:

* write personality pages for each other,
* leave funny observations and memorable moments,
* document team culture,
* and build a shared internship memory archive together.

Unlike ordinary profile systems, the content is written collaboratively by peers, which made the experience surprisingly fun and engaging.

The screenshots above are from my own page — and most of the content was actually written by other interns.

People added:

* personality traits,
* work style descriptions,
* social reputation,
* memes,
* funny incidents,
* and random inside jokes.

As interns kept updating pages daily, the platform naturally became:

* an icebreaker,
* a bonding tool,
* and a shared community space.

---

## 💡 Why I Built It

I wanted to create something beyond just “another internal tool.”

The goal was:

* helping interns get closer faster,
* creating memorable interactions,
* encouraging participation,
* and making company life feel more human and fun.

Instead of formal introductions, people learned about each other through collaboratively written wiki pages.

And honestly…

Watching interns laugh at their own pages or continuously edit each other’s entries became one of the most rewarding parts of the project.

## 🚀 Features

* 🌳 Namuwiki-inspired UI/UX
* 🔍 Real-time wiki search
* 👤 Personal profile pages
* 🏢 Team pages & organization structure
* ✏ Collaborative editing system
* 📝 Audit log tracking for edits
* 🖼 Image upload support
* 🎨 Rich text styling system
* 🔗 Internal page linking (`[[page|label]]`)
* 🔐 Login-restricted internal access
* 📜 Version / edit history
* ⚡ Real-time synchronization with Supabase
